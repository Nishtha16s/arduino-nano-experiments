# Experiment 23: Potentiometer & PWM - Potentiometer Controlled Buzzer Pattern

Arduino Nano | Analog Input | map() Function | tone() Function

## Objective
To learn how to use a potentiometer to control the pitch of a buzzer by changing the frequency generated by the Arduino Nano.

## Introduction
A potentiometer can provide a variable analog value depending on the position of its knob. The Arduino reads this value using an analog input pin.

In this experiment, the potentiometer is connected to A0 and the buzzer is connected to digital pin D8. The potentiometer reading is converted from a range of 0-1023 into a frequency range of 200-2000 Hz. As the potentiometer is rotated, the frequency sent to the buzzer changes, producing a changing pitch.

## Connection Explanation
The potentiometer has three pins. Its two outer pins are connected to 5V and GND, while the middle pin provides a variable voltage to the Arduino's A0 analog input.

The buzzer is connected to D8. The Arduino generates a tone on this pin using the `tone()` function. When the potentiometer is rotated, the voltage at A0 changes. The Arduino reads this value and converts it into a buzzer frequency between 200 Hz and 2000 Hz.

## Build Steps

2. Connect one outer pin of the potentiometer to 5V.
3. Connect the other outer pin to GND.
4. Connect the middle pin to A0.
5. Connect the positive terminal of the buzzer to D8.
6. Connect the negative terminal of the buzzer to GND.
7. Connect the Arduino Nano to the computer using USB.
8. Select the correct board and port in the Arduino IDE.
9. Upload the sketch.
10. Rotate the potentiometer and observe the change in buzzer pitch.

## Arduino Code
See [exp23_pot_controlled_buzzer_pitch.ino](exp23_pot_controlled_buzzer_pitch.ino)

```cpp
const int POT = A0;    // Potentiometer middle pin connected to A0
const int BUZZ = 8;    // Buzzer connected to D8

void setup() {
  pinMode(BUZZ, OUTPUT);
}

void loop() {
  // Convert potentiometer reading (0-1023) into frequency (200-2000 Hz)
  int freq = map(analogRead(POT), 0, 1023, 200, 2000);

  tone(BUZZ, freq);   // Play the selected frequency
  delay(50);          // Short delay before the next reading
}
```

## How the Program Works
- `POT = A0` defines A0 as the potentiometer input.
- `BUZZ = 8` defines D8 as the buzzer output.
- `analogRead(POT)` reads the potentiometer value from approximately 0 to 1023.
- `map()` converts this value into a frequency between 200 Hz and 2000 Hz.
- `tone(BUZZ, freq)` generates the selected frequency on the buzzer.
- `delay(50)` gives a short delay before reading the potentiometer again.

## Working Principle
Rotate Potentiometer → Analog Value Changes → Arduino Reads A0 → Value Converted to Frequency → Buzzer Pitch Changes

The potentiometer acts like a simple pitch control. Turning the knob changes the frequency generated by the Arduino.

## Analog Reading to Frequency Mapping

| Potentiometer Reading | Approx. Frequency | Pitch     |
|----------------------:|------------------:|-----------|
| 0                     | 200 Hz            | Very Low  |
| ~256                  | ~651 Hz           | Low       |
| ~512                  | ~1101 Hz          | Medium    |
| ~768                  | ~1551 Hz          | High      |
| 1023                  | 2000 Hz           | Very High |

## Understanding Frequency
Frequency determines how high or low a buzzer sounds.
- Lower frequency → lower pitch
- Higher frequency → higher pitch
- 200 Hz → low pitch
- 2000 Hz → high pitch

The `tone()` function generates the required frequency on the buzzer.

## Expected Output
When the potentiometer is rotated:
- At the minimum position, the buzzer produces a low pitch.
- At the middle position, the buzzer produces a medium pitch.
- At the maximum position, the buzzer produces a high pitch.
- Rotating the knob continuously changes the pitch.

The circuit behaves like a simple variable-pitch electronic instrument.

## Important Note
The pitch changes with frequency only when a **passive buzzer** is used. An active buzzer has a built-in oscillator, so it produces one fixed tone regardless of the frequency value.

## Precautions
1. Connect the potentiometer middle pin to A0.
2. Make sure the potentiometer's outer pins are connected to 5V and GND.
3. Check the buzzer polarity before powering the circuit.
4. Do not create a direct connection between 5V and GND.
5. Check all connections before uploading the program.
6. Do not change circuit connections while the Arduino is powered.
